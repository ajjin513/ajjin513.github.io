Paris Olympic Data Visualization

A walkable, side-scrolling data story built with p5.js.

Role
Designer & Developer
Year
2024
Stack
JavaScript, p5.js
Links
Live demo · Code

Overview

Instead of a static chart, this project lets you walk through Paris. You steer an illustrated character with the arrow keys past landmarks like the Eiffel Tower and the Louvre, and press Q to interact with each scene and uncover Olympic data along the way.

How it's built

  • Original illustrations for the character, trees, and landmarks
  • Sprite-sheet walking animation and a camera that follows the player
  • Keyboard interaction and animated elements such as a rising French flag
